## andrea/

Andrea Lopez-Luzuriaga's skills kit, as its starter package: 51 files, version v2.5 (October 10, 2026). It is the version of her kit with everything that identifies a person or an organization removed. Start with `andrea/README.md`, then `andrea/CHANGELOG.md`.

- **Source:** `aflopezluzuriaga/SkillPropagation` (private), `kit/starter_package/`, commit `cf9e108`. The files here are byte copies.
- **Not mixed with the template.** These files keep the kit's own names and layout (`<name>_skill.md`, one flat folder). A skill enters `template/skills/` only when it is ported there by hand, with a provenance line that cites the source above.
- **Replaced whole, never edited in place.** Each new version of the package replaces the folder. A change to one of these files is proposed to Andrea, who makes it in her kit.
